# Database

| Berkas | Isi |
|---|---|
| `instal-lengkap.sql` | seluruh tabel, aturan akses, fungsi, dan isi acuan |
| `contoh-kata-visi.sql` | contoh isian kata kunci visi keilmuan; tidak membuat tabel |

Jalankan `instal-lengkap.sql` sekali di **SQL Editor** pada proyek Supabase
kosong (`README.md` langkah 2). Berkas ini tidak menghapus apa pun: kalau
tabelnya sudah ada, ia berhenti dengan galat `already exists` dan data tetap aman.

Berkas ini dibuat otomatis dari kode sumber. Jangan disunting tangan.
